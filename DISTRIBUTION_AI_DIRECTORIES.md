### Fork → edit → PR steps (brief)

1. **Fork** the target repo on GitHub (Fork button, top right).
2. **Edit the README** directly in the GitHub web UI (pencil icon) — find the right category, add the one-line entry in alphabetical order if the list is alphabetized.
3. **Commit** to a new branch, e.g. `add-spur-ai`, with message: `Add Spur AI (Claude-powered LinkedIn content engine)`.
4. **Open the Pull Request** against the upstream repo's default branch. In the PR description, note: what it is (1 line), that it's built on Anthropic's Claude, and that it offers free no-signup tools. Confirm you followed the list's formatting/category rules.
5. **Follow the CONTRIBUTING checklist** if present (some lists require the entry be alphabetized, HTTPS-only, no trailing period, or a short description length) and check any "PR template" boxes.

All GitHub steps require a logged-in GitHub account — **OWNER** action.
